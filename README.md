
# Medical Inventory Management System (Medical Goods)

This is a **Medical Inventory Management System** developed in **C#**. The application is designed to help clinics, hospitals, and medical suppliers efficiently manage their stock of medical supplies, equipment, and consumables.

## Features

- 🏥 Track medical items by category, quantity, and expiry date  
- 📦 Add, edit, and delete products from the inventory  
- 🔍 Search and filter items by name, category, or status  
- 🔔 Automatic alerts for low stock or near-expiry items  
- 🧾 Generate inventory reports  
- 👤 User authentication and role-based access  
- 💾 Data persistence using a local database (e.g., SQL Server)

## Technologies Used

- **Language**: C#  
- **Framework**: .NET (WinForms)  
- **Database**: SQL Server  
- **IDE**: Visual Studio  

## Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/medical-inventory-manager.git
   ```
2. Open the solution file (`.sln`) in Visual Studio.
3. Restore NuGet packages if required.
4. Update the connection string in `App.config` or `Settings.cs` to match your database.
5. Build and run the application.
